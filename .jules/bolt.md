## 2025-03-05 - [Initial performance profile for Jekyll theme]
**Learning:** Default Jekyll remote themes often lack modern performance optimizations like resource pre-fetching, pre-connecting, and efficient font delivery. Overriding the default layout is the most effective way to implement these optimizations without significant architectural changes.
**Action:** Always check the `_layouts/` and `_includes/` directories for opportunities to override and optimize the base theme's HTML structure.
